🎬 MovieVault

A cross-platform desktop app for organizing and tracking movies.

Problem

I often forgot which movies I wanted to watch, which ones I had already watched, and what I thought about them afterward.

Solution

I built MovieVault, a desktop application where users can manage movies with custom tags, track reviews, and fetch movie data from TMDB.

Key Features

  • Add & organize movies with custom tags
  • Track ratings, reviews, and watch history
  • Sync posters and metadata automatically
  • Review system with profile support
  • Modern UI with gradient overlays for readability

Challenges & Learnings

- Integrated SQLite with Express efficiently using better-sqlite3
- Solved issues with missing poster images and conditional API calls
- Implemented regex filtering to clean messy TMDB cast data
- Learned to structure an Electron + React app with a maintainable backend/frontend split
